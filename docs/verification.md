## Четыре работающих приложения

`python3 scripts/smoke.py` прошёл через настоящий Gateway и Eureka: регистрация, JWT, роли, traceId, CRUD, даты, собственная история, повтор requestId, отмена, гонка из 12 запросов на один номер (ровно одно подтверждение), рекомендации, равномерность распределения и статистика занятых ночей.

`python3 scripts/fault-smoke.py` прошёл с настоящими Hotel и отдельным Booking JVM:

- Hotel фиксирует выделение; прокси теряет все три ответа. Счётчик номера увеличивается один раз.
- Booking переходит в CANCELLED; недоступная операция release оставляет задачу компенсации в БД.
- После снятия сбоя фоновый обработчик освобождает календарь.
- Поздний повтор allocate получает 409 и не занимает слот.
- Новый запрос после временного 503 успешно повторяется; повтор requestId и последующая отмена остаются согласованными.

Для локальной проверки использованы свободные порты 18080/18081/18082/18761. Значения по умолчанию остаются 8080/8081/8082/8761. Конфигурация Docker Compose проходит `docker compose config -q`; полный запуск проверен через JAR. CI содержит ту же Maven-проверку и оба сквозных сценария на Linux.
